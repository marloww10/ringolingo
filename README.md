# 📱 Sobre o Projeto

O **RingoLingo** é um aplicativo mobile que permite praticar inglês através de **conversas com personagens virtuais alimentados por inteligência artificial**.

O aplicativo simula situações reais de comunicação, como:

- entrevistas de emprego  
- conversas com amigos  
- interações em restaurantes  

Dessa forma, o usuário consegue praticar **conversação e compreensão** em um ambiente interativo.

As conversas dentro do aplicativo acontecem **exclusivamente por texto**: o Ringo envia uma mensagem e o usuário responde também com texto.  
Atualmente o sistema **não possui suporte para voz ou áudio**, sendo totalmente baseado em chat.

O objetivo é tornar o aprendizado de idiomas **mais natural, acessível e motivador**.

# 🧱 Arquitetura do Projeto

O sistema é dividido em duas camadas principais.

## Aplicação Mobile

Responsável pela interface do usuário e experiência de aprendizado.

Funções principais:

- interação com os personagens (Ringos)
- envio e recebimento de mensagens de texto
- acompanhamento de progresso do usuário
- autenticação e sessão
- renderização das telas e experiência de navegação do aplicativo

## Backend

Responsável pelo processamento das regras de negócio.

Funções principais:

- gerenciamento de usuários
- integração com inteligência artificial
- armazenamento de histórico de conversas
- controle de progresso e dados do usuário

Além da arquitetura técnica, o projeto também inclui o **design das telas do aplicativo e dos personagens (Ringos)**, que representam diferentes contextos de conversa para prática do inglês.
